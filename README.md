# Seoul Heat Shelter Explorer

서울시 무더위쉼터의 500m 격자별 접근성 지도와 분석 보고서입니다.

- `index.html`: 격자·시설 탐색 지도
- `report.html`: 자료·전처리·지표 수식·지도와 산점도 해석
- `data/`: 웹 지도용 격자·시설·15분 이용권 자료
- `report-assets/`: 보고서 지도·산점도

## 로컬 실행

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 별도 빌드 과정은 없습니다.

## Cloudflare Pages

GitHub 저장소의 `main` 브랜치를 선택합니다. 프레임워크는 None, 빌드 명령은 `exit 0`, 출력 디렉터리는 `.`으로 설정합니다. 저장소 루트에 `index.html`이 있습니다.

## 자료와 해석

쉼터는 행정안전부 재난안전데이터공유플랫폼 자료이며, 레코드의 YEAR 필드는 2026입니다. 인구는 2024년 격자 자료입니다. 시점 차이, 수용인원 대체 및 극단값, 네트워크 한계는 보고서에 명시했습니다. 지도 배경 자치구 경계는 KOSTAT 2013 자료로 위치 참고용입니다. 상세 출처와 검증 범위는 보고서를 참고하세요.
